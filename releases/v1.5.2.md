# 🔔 NodoPin v1.5.2 (68) — Notificaciones FCM restauradas y seguridad reforzada

**Esta actualización consolida la recuperación de las notificaciones de NodoPin para Android y cierra el diagnóstico temporal utilizado para localizar la incidencia, sin alterar las funciones que ya estaban operativas.**

## 📲 Notificaciones y conexión

- 🔔 **Firebase Cloud Messaging (FCM) recuperado:** corregido el flujo de registro del dispositivo para volver a recibir notificaciones push.
- 🔄 **Identificador de instalación (FID):** mantenido el registro y la renovación de la identidad de instalación de Firebase y de sus credenciales de notificación, evitando depender de un identificador desactualizado.
- 🛡️ **Asociación de dispositivo protegida:** se conservan la autenticación del dispositivo y la prueba de posesión exigidas para el registro de notificaciones.
- ✅ **Funcionamiento recuperado:** la recepción FCM volvió a operar tras las correcciones y comprobaciones realizadas.

## 🔐 Seguridad y limpieza de diagnóstico

- 🧹 **Diagnóstico temporal retirado de la compilación Android:** eliminadas las trazas de diagnóstico introducidas para localizar el fallo, después de confirmar la recuperación del servicio.
- 🔒 **Protecciones existentes preservadas:** se mantienen Firebase App Check y los controles de autorización P1/P2, sin rebajar sus comprobaciones.
- 🧩 **Cambio delimitado:** no se modifica el cifrado de las conversaciones, el funcionamiento de grupos, la Web App, las copias en Google Drive ni los datos existentes.

## 💬 Funciones que se conservan de v1.5.1

- 🔐 Mensajería privada cifrada entre Android y Web y notas de voz.
- 👥 Grupos, mensajes y contenido multimedia cifrado, con estados de entrega y lectura cuando hay confirmación real.
- 📌 Hasta cinco conversaciones fijadas; contactos QR/NFC y tarjetas verificadas.
- ☁️ Copia integral cifrada y recuperación de cuenta con Google.
- 📲 Actualizador oficial con validación de integridad SHA-256.

## ⬇️ Cómo actualizar

1. Descarga el archivo oficial **`nodopin.apk`** desde los archivos adjuntos de esta publicación una vez publicada.
2. Instálalo **encima de la versión anterior, sin desinstalar NodoPin ni borrar tus datos**.
3. Conserva previamente tu copia cifrada y la clave de recuperación.

**Importante:** la actualización automática y el archivo `nodopin/version.json` se modificarán únicamente después de adjuntar y verificar el APK final y publicar la versión. Este borrador no activa una actualización.
